# Sitio de Paula Cucurella (bilingüe)

Sitio estático de una sola página (SPA) para GitHub Pages, con dominio `paulacucurella.com`.

- `index.html` — el sitio completo (bilingüe ES/EN, navegación por secciones).
- `assets/Paula-Cucurella-CV-2026.pdf` — CV descargable.
- `CNAME`, `.nojekyll`, `robots.txt`, `404.html` — configuración de publicación.

## Editar
Todo el contenido y estilos están en `index.html`. Los textos bilingües usan
`<span class="es">…</span><span class="en">…</span>`. El idioma se elige en la
portada y se cambia con el botón ES/EN del menú.

## Publicar
Ver `GUIA-MIGRACION.md`. En resumen: subir estos archivos al repositorio →
Settings → Pages → rama main → dominio `paulacucurella.com`.
